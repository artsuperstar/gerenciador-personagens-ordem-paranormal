# Arquivo de Agentes

Gerenciador local de fichas para agentes, construído com React, TypeScript e Vite.

> Este é um conteúdo não oficial, publicado sob a Licença da Comunidade de Ordem Paranormal.
>
> Contém material gerado por inteligência artificial.

O projeto possui identidade própria, não usa marcas ou artes oficiais e não implementa cálculos de regras ainda não confirmados.

## Desenvolvimento

```sh
npm install
npm run dev
```

As fichas são salvas automaticamente no `localStorage` do navegador e não são enviadas a um servidor.

## Primeira etapa

- Modelo extensível para informações básicas, atributos, perícias, recursos, combate, inventário, ataques, habilidades, rituais, elementos, condições e histórico
- Criação, seleção, edição e exclusão de agentes
- Persistência independente por personagem
- Interface integralmente em português brasileiro
- Edição de informações básicas, PV, PE, Sanidade e anotações
- Edição dos cinco atributos base e das perícias oficiais, com bônus de Treino e Outros
